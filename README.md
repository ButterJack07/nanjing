# 金陵城区 · 开放世界沙盒

**在线游玩：https://butterjack07.github.io/nanjing/**

一个可在浏览器直接游玩的 3D 城市沙盒原型。使用 Three.js + Vite，程序化生成街道、建筑、公交、地铁与可进入的室内空间。

> 非官方作品。城市布局只参考南京中心城区的相对方位与道路关系，不是测绘地图；南京大学鼓楼校区为风格化还原，建筑尺度与楼位仍需可靠底图校准。与 Rockstar Games、GTA 系列及南京大学无关联。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`，预览：`npm run preview`。

## 已实现

- **城市**：新街口、鼓楼、珠江路、大行宫、上海路、张府园、三山街、夫子庙、总统府、玄武湖、明城墙等片区；主干道、次干道、街巷分层路网，弯曲湖岸与秦淮河。
- **南京大学鼓楼校区**：按汉口路、广州路、上海路、青岛路围合的片区定位；北大楼、大礼堂、教学楼、南园宿舍、食堂、操场，校园内可直接步行，图书馆可进入并预留校史任务点。
- **连续室内**：便利店（货架偷窃、撬仓库门）、银行（大厅、撬金库门、拿现金）、鼓楼酒店（四层、楼梯、实际升降电梯与客房）、校园图书馆。无进出场动画，直接走入。
- **地铁 B1 站**：1 号线（鼓楼—珠江路—新街口—张府园—三山街）与 2 号线（上海路—新街口—大行宫），按真实站序。每站是紧凑的下沉式 B1 站厅：街边楼梯直接走下去，站内有售票闸机、站台屏蔽门、线路图、候车座椅与实体列车；列车到站开门，站台按 E 上下车，全程无过场。
- **公交 01 线**：鼓楼公交场—鼓楼—珠江路—新街口—大行宫—大行宫公交场；两辆 AI 公交往返，港湾式站台、乘客上下车；可驾驶共享公交接临时班次（每站 $60，完成 +$300），或乘坐 AI 公交。
- **出租车**：手机选任意目的地后叫车，车辆沿路来接，按 E 乘坐并付费。
- **街头**：停放车辆、AI 车流、行人；偷车/撞车/开火触发通缉，警车追捕、搜索与截停。
- **手机**：地图拖动缩放、地点导航、公交、打车、沙盒工具（金币/物资/武器/清除通缉/生成车辆）。
- **移动端**：默认横屏全屏。首次触摸会自动请求全屏并尝试锁定横屏，横屏下显示触屏方向键、交互与射击按钮；竖屏时显示旋转/全屏入口。iOS Safari 可能不支持屏幕方向锁定，需要手动开启旋转锁定。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 步行 / 驾驶 |
| E | 交互、上下车、进站乘车、电梯 |
| F（按住） | 撬锁；手机可直接点交互按钮 |
| Shift / Space | 奔跑加速 / 跳跃手刹 |
| 1 / 2 / 3 | 徒手 / 手枪 / 冲锋枪 |
| 鼠标右键拖动 / 左键 | 瞄准 / 射击 |
| P / Esc | 打开 / 收起手机 |
| M | 手机地图 |
| Tab | 显示 / 隐藏 HUD |
| R | 回到新街口 |

## 已知限制

- 这是一份风格化游戏地图，不是南京真实道路、校园或地铁的精确复刻；站名、站序与相对位置参考现实，站体、出口、公交站杆与校园楼位仍需底图校准。
- 3、4 号线只保留在规划图中，尚未建模。地铁列车按线路端点折返运行，不是完整调度系统。
- 公交、车流与行人使用简化的路线和距离判断，没有完整交通信号、避让与碰撞物理。
- 通缉、金钱与任务状态仅保存在当前页面会话，刷新即重置。

设计草案见 `planning.html`。
