# 金陵城区 · 开放世界沙盒

**在线游玩：https://butterjack07.github.io/nanjing/**

一个可在浏览器直接游玩的 3D 城市沙盒原型。使用 Three.js + Vite，程序化生成街道、建筑、公交、地铁与可进入的室内空间。进入游戏先选择地图：**金陵城区**（市中心 + 地铁）或 **南京大学 · 仙林校区**（校园 + 校车）。

> 非官方作品。城市布局只参考南京中心城区的相对方位与道路关系，不是测绘地图；南京大学鼓楼校区、仙林校区均为风格化还原，建筑尺度与楼位仍需可靠底图校准。与 Rockstar Games、GTA 系列及南京大学无关联。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`，预览：`npm run preview`。

## 已实现

- **地图选择**：进入游戏先选地图，手机「设置」页可随时切换；两图共用同一套玩法（驾驶、行人、通缉、手机、公交、跑腿、沙盒工具）。
- **城市**：新街口、鼓楼、珠江路、大行宫、上海路、张府园、三山街、夫子庙、总统府、玄武湖、明城墙等片区；主干道、次干道、街巷分层路网，弯曲湖岸与秦淮河。
- **南京大学鼓楼校区**：按汉口路、广州路、上海路、青岛路围合的片区定位；北大楼、大礼堂、教学楼、南园宿舍、食堂、操场，校园内可直接步行，图书馆可进入并预留校史任务点。
- **南京大学仙林校区（第二张地图）**：按 OpenStreetMap 真实数据重建 —— 道路中心线（南雍大道、中大路、三江路、两江路、金大路、汇文路、天启路等）、建筑坐标与校区轮廓均由经纬度投影到游戏米制（1 单位 = 1 米）。含杜厦图书馆、敬文学生活动中心、校史馆、游泳馆、方肇周体育馆、学生食堂、各系馆与学生公寓；可进入建筑含图书馆、食堂、宿舍楼、活动中心、体育馆、游泳馆、校史馆与便利店。无地铁，改为**校园校车**环绕各站。
- **出生房（仙林 · 南门外）**：出生即进入带墙的出生房，屋内是**情报板**（版本号 + GitHub 最新推送日期）、**武器墙**（可无限领取武器弹药）、**补给箱**（弹药 / 开锁器 / 生命）与两座**展示台**（陈列后续交互道具）。房外停车区停着全部载具：跑车、吉普、电动车、警车、公交、直升机与运动型小飞机。
- **连续室内**：便利店（货架偷窃、撬仓库门）、银行（大厅、撬金库门、拿现金）、鼓楼酒店（四层、楼梯、实际升降电梯与客房）、校园图书馆、德基广场（3 层，3F 美食档取餐）、三栋 6 层居民楼（逐层楼梯、房门、门牌）。无进出场动画，直接走入。
- **地铁 B1 站**：1 号线（鼓楼—珠江路—新街口—张府园—三山街）与 2 号线（上海路—新街口—大行宫），按真实站序。每站是紧凑的下沉式 B1 站厅：街边楼梯直接走下去，站内有售票闸机、站台屏蔽门、线路图、候车座椅与实体列车；站间有隧道，列车到站开门，站台按 E 上下车，全程无过场。
- **公交 / 校车**：鼓楼公交场—鼓楼—珠江路—新街口—大行宫—大行宫公交场（仙林校区为南门—图书馆—宿舍—体育馆—活动中心—西门）。站点数据写在各自地图里、落在道路中心线上，两辆 AI 车双向循环，港湾式站台与乘客上下车；可驾驶共享公交接临时班次（每站 $60，完成奖金），或乘坐 AI 车。公交卡死会自动重新寻路。
- **出租车**：手机选任意目的地后叫车，车辆沿路来接，按 E 乘坐并付费。
- **跑腿配送**：手机「跑腿」页接单 → 德基广场 3F 美食档取餐 → 按导航爬到居民楼指定楼层敲门送达，现金结算。
- **载具**：自行车、轿车、跑车、越野吉普、电动车、面包车、皮卡、公交、地铁（金陵城区）、直升机、固定翼飞机；**警车也可驾驶**。直升机/飞机可自由升降，停稳落地后才能下机。
- **街头**：停放车辆、AI 车流、52 名沿街行人；行人被撞会倒地并触发通缉，车辆之间会互相阻挡碰撞，行人也会避让行驶中的车辆。
- **手机**：地图拖动缩放、地点导航、公交、打车、跑腿、沙盒工具（金币/物资/武器/清除通缉/生成车辆）。
- **移动端**：默认横屏全屏。首次触摸会自动请求全屏并尝试锁定横屏；横屏下左侧是摇杆（推到最上方锁定奔跑），右侧是交互键与跳跃键，点按画面开火。驾驶时左下出现「◀ / ▶」转向键，右下是「油门 / 刹车」与「D 挡 / R 挡」切换，飞行时改为「升 / 降」；转向可用手机倾斜（面板上的「⦿ 校准」或手机设置页可随时重设水平基准），也可用摇杆横向当方向盘。竖屏时显示旋转/全屏入口。iOS Safari 可能不支持屏幕方向锁定，需要手动开启旋转锁定。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 步行 / 驾驶 |
| E | 交互、上下车、进站乘车、电梯 |
| F（按住） | 撬锁；手机可直接点交互按钮 |
| Shift / Space | 奔跑加速 / 跳跃手刹（飞行时 Space 上升、Shift 下降） |
| 1 / 2 / 3 | 徒手 / 手枪 / 冲锋枪 |
| 鼠标右键拖动 / 左键 | 瞄准 / 射击 |
| 手机左摇杆 | 移动，推到最上方锁定奔跑 |
| 手机右侧 | 交互键、跳跃键；点按画面开火 |
| 手机驾驶 | 左下「◀ / ▶」转向，右下「油门 / 刹车」；「D 挡 / R 挡」切换前进与倒挡；飞行时「升 / 降」 |
| 手机转向校准 | 驾驶面板「⦿ 校准」或手机设置页，摆正手机后点击重设水平基准 |
| P / Esc | 打开 / 收起手机 |
| M | 手机地图 |
| Tab | 显示 / 隐藏 HUD |
| R | 回到出生点 |

## 已知限制

- 这是一份风格化游戏地图，不是南京真实道路、校园或地铁的精确复刻；站名、站序与相对位置参考现实，站体、出口、公交站杆与校园楼位仍需底图校准。
- 仙林校区同样为风格化还原，按南门—中心轴—图书馆等相对关系布置，不是测绘底图；该地图没有地铁，校内交通由校车承担。
- 3、4 号线只保留在规划图中，尚未建模。地铁列车按线路端点折返运行，不是完整调度系统。
- 公交、车流与行人使用简化的路线和距离判断，没有完整交通信号与避让；飞行器没有三维建筑碰撞的精细判定，低空会与楼体互相阻挡，高空可自由飞越。
- 通缉、金钱与任务状态仅保存在当前页面会话，刷新即重置。

## 更新记录

- **仙林校区改用真实数据重建**：从 OpenStreetMap 提取了仙林校区的**建筑轮廓多边形（195 处，含未命名建筑）**、道路中心线、绿地/水面多边形与校区轮廓，投影为游戏坐标（1 米 = 1 单位）并挤出建模，平面形状与相对位置与真实底图一致；此前凭印象布置的方块布局已全部替换。杜厦图书馆、南门、各院系楼、食堂、宿舍、天文台等均按真实位置摆放。
- **出生点载具归位 + 飞机朝向修复**：仙林地图的跑道与固定翼飞机原来刷在出生房以西约 360 米处，现已移到出生房西侧的短跑道（与东侧停车区对称），直升机在停机坪、飞机在跑道，全部载具紧邻出生房。同时修复了直升机和固定翼飞机模型朝向与行驶方向相反（“倒着飞”）的问题。
- **直升机操控修复**：此前转向速率与飞行速度绑定，悬停（速度为 0）时按 A/D 或左右方向键完全无法转向，感觉“方向键失灵”。现在直升机像尾桨一样可以原地偏航，转向速率只随速度轻微增加；固定翼飞机仍需要空速才能转弯。

- **双地图与选择菜单**：进入游戏先选择「金陵城区」或「南京大学 · 仙林校区」，两图共用同一套系统；场景、世界数据与载具在切换时整体重建并释放，手机「设置」页可再次切换。
- **南京大学仙林校区**：新增第二张地图 —— 仙林大道与南门、中心轴、杜厦图书馆、学生第一食堂、学生宿舍、活动中心、方肇周体育馆、校史馆、田径场、明湖与外围城市街区；可进入建筑复用同一套室内系统。此图不含地铁，改用校园校车。
- **出生房与领取物品**：南门外出生房内提供情报板（版本 + GitHub 最新推送日期，运行时会调用 GitHub API 刷新）、无限武器墙、补给箱与展示台；房外停放全部载具（含吉普、电动车与可驾驶警车）。
- **公交系统修复**：站点改为按地图数据驱动、落在道路中心线上；路线车双向循环、到站开门与乘客上下车；新增卡死自恢复（长时间无法前进会重新寻路），班次奖金改为按实际站数结算。
- **车辆**：新增越野吉普与电动轿车两种车型；警车（非 AI 追捕者）现在可以驾驶。
- **手机驾驶方式**：驾驶时左下为「◀ / ▶」转向键，右下为「油门 / 刹车」，并提供「D 挡 / R 挡」切换前进与倒挡；飞行器改为「升 / 降」键。可与摇杆、倾斜转向同时使用。
- **转向校准与方向修正**：修正了手机倾斜转向左右相反的问题；新增转向校准，可在驾驶面板点「⦿ 校准」或到手机「设置」页重设水平基准，传感器只绑定一次监听。
- **安全细节**：上车时自动回到 D 挡并重置倾斜基准；打开手机、失焦或下车时清空所有驾驶按键状态，避免输入卡住。
